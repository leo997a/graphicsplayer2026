# Graphics Player 2026

Professional collection of football player graphics (faces) organized by league and club.

## Structure

The repository is organized hierarchically for easy navigation and scaling:

```
Leagues/
└── La Liga/
    └── FC Barcelona/
        ├── faces/        # High-quality .png face graphics
        └── players.json  # Mapping of player names to direct raw URLs
```

## How to use

You can access the player images directly using the URLs provided in the `players.json` files within each club's directory. These URLs point to the `raw.githubusercontent.com` version of the images, making them ideal for use in web applications or broadcast tools.
